## 📞 Quick Reference

### Common Time Complexities:
- **O(1)**: Bit ops, Math basics
- **O(log n)**: Binary search, Balanced trees
- **O(n)**: Linear search, Single traversal
- **O(n log n)**: Good sorting, Heaps
- **O(n²)**: Nested loops, DP, Matrix
- **O(2^n)**: Permutations, Subsets
- **O(n!)**: Full permutations

### Common Space Complexities:
- **O(1)**: No extra space
- **O(n)**: Arrays, Stacks, Queues
- **O(log n)**: Recursion depth
- **O(n²)**: 2D DP tables
