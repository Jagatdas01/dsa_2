- **BasicOperations.java**

## 📌 Common Patterns Quick Reference

| Pattern | Time | Space | Examples |
|---------|------|-------|----------|
| Linear Search | O(n) | O(1) | Find element |
| Binary Search | O(log n) | O(1) | Sorted search |
| Two Pointer | O(n) | O(1) | Pair sum, Container |
| Sliding Window | O(n) | O(k) | Substring, Window max |
| DFS | O(V+E) | O(h) | Tree traversal |
| BFS | O(V+E) | O(w) | Level order |
| Merge Sort | O(n log n) | O(n) | Sorting |
| Quick Sort | O(n log n)* | O(log n) | Sorting |
| DP | Varies | Varies | Optimization |
