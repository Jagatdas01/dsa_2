## 📊 Complexity Cheat Sheet

### Time Complexities (from fastest to slowest)
```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2^n) < O(n!)
```

### When Each is Used:
- **O(1)**: Direct access, hash lookup, bit operations
- **O(log n)**: Binary search, balanced trees
- **O(n)**: Linear search, single traversal
- **O(n log n)**: Good sorting, heap operations, divide & conquer
- **O(n²)**: Nested loops, bubble sort, basic DP
- **O(n³)**: Matrix multiplication, 3D DP
- **O(2^n)**: Subset generation, exponential recursion
- **O(n!)**: Permutation generation

### Space Complexities:
- **O(1)**: No extra space, in-place
- **O(log n)**: Recursion depth
- **O(n)**: Arrays, lists, queues, stacks
- **O(n²)**: 2D arrays, DP tables
- **O(n!)**: All permutations

## 🎯 Algorithm Selection Guide

**Given a problem, how to choose?**

### Array/String Search:
- Sorted → Binary Search O(log n)
- Unsorted → Linear Search O(n)
- Multiple queries → Hash Set O(1)

### Sorting:
- General → Merge/Quick Sort O(n log n)
- Almost sorted → Insertion O(n)
- Limited range → Counting O(n + k)

### Graph Problems:
- Shortest path → Dijkstra O((V+E) log V)
- All pairs → Floyd O(V³)
- Connectivity → Union-Find O(α(n))

### Optimization:
- Greedy choice → Greedy algorithm
- Optimal substructure → Dynamic Programming
- Exponential search → Backtracking

### Traversal:
- Level by level → BFS O(V+E)
- Deep first → DFS O(V+E)
- Ordered → In-order traversal O(n)
